# UX Psychology

Umuryango handles decisions and records that affect trust between family
members. The experience should reduce uncertainty without using manipulation.

- Show the next action and its consequence before confirmation.
- Preserve drafts and entered values through recoverable errors and sign-in.
- Pre-fill only when the default is explainable and changeable.
- Warn about real loss: unsaved data, duplicate submission, irreversible
  deletion, or an expired synchronization window.
- Do not use fake urgency, confirm-shaming, hidden fees, or preselected consent.
- Make offline work feel deliberate: identify what is saved locally, what is
  pending, and what still needs server confirmation.
- After a retry, show whether the result was accepted, already applied, or
  still pending.
- Make permissions understandable before a member performs a restricted action.

Trust is a product requirement. A technically correct flow that makes users
uncertain whether money was recorded is not acceptable.
