# UI Clarity

- Show the primary financial value first.
- Keep currency visible near monetary amounts.
- Keep family scope, date, member, category, and status visible when they are
  needed to interpret a record.
- Avoid repeating a title in the first card or restating labels in paragraphs.
- Use short action labels, usually one or two words.
- Distinguish no records yet, no matching records, offline data, and failed
  loading.
- Empty states explain what is missing and provide the next useful action.
- Error states preserve entered data and explain whether retrying is safe.
- Do not use color alone for positive, pending, failed, or conflict status.
- Preserve accessible names for icons and compact controls.

Clarity does not mean removing context. A clean screen that hides the family,
member, date, currency, or synchronization state is not a successful screen.
